# Federal Fiscal Optimizer

Public source code and documentation for reproducible R models of federal fiscal policy, debt dynamics, and Social Security solvency.

## Published models

- [`protected-policy-set-excluded-from-cuts`](models/protected-policy-set-excluded-from-cuts/README.md)  
  Optimizes a federal fiscal package while excluding the defined protected policy set from cuts and other prohibited burdens. The model directory contains the executable R script, fixed inputs, methodology, and reproduction instructions.
